## Completed Source Changes

- `MessagePage.kt`: preserve shared-role pin/recall behavior while separately
  gating unpin by actor/pinner roles. Admin cannot unpin the current owner's pin;
  missing pinner role is conservatively denied except for the actor's own pin.
  Owner retains unpin authority. Apply the gate to bar, menu and dispatch.
- Pin reads use page-local latest-request ordering and cancellation checks, so
  older in-flight reads cannot resurrect removed pins. Existing real-time
  projection/foreground/30-second refresh paths remain in use; reconnect effect
  now also keys on channel identity.
- Opened pin-list selection captures its displayed list. A subsequent refresh
  cannot redirect the same selected index to a different server message.
  Source anchors match channel and server message identity, never local row ID.
  Missing source retains the existing localized unavailable-message hint.
- Hide remains page-local presentation only, survives list refresh, and has no
  mutation callback/RPC. No pin count limit, announcement or eviction was added.
- `ChatSettingsPage.kt`: member name/description cells have null click handlers,
  not fake editable rows. Owner/admin name editing is restored. Group description
  reads also refresh on connection-state changes, in addition to projection
  invalidation/page entry and existing app foreground invalidation.
- Description editor locks input/save/dismiss while saving, prevents duplicate
  writes, preserves draft on failure, supports explicit empty-string clear, and
  ignores pre-write/out-of-order reads. Projection refresh does not replace an
  active draft. Success invalidates the projection for authoritative reread.
- `GroupNameEditPage.kt`: preserves the public real-save callback contract,
  validates the current spec's 30 Unicode-scalar bound and C0/C1 exclusions,
  shows scalar count, and guards duplicate submission/input/back while saving.
- Group-specific error presentation reuses existing `UserFacingError` parsing
  and existing language packs. Existing IM codes 10004/10100 select localized
  permission/profile-validation text; network uses the existing mapper and
  unknown failures use localized action fallback. Raw server text is not shown.
